SnowLuma 上游仓库已不再公开，桌面端移除其全部下载入口；已安装的机器保留完整管理能力。

### 更新内容

#### SnowLuma 下载入口移除

- 组件页不再提供 SnowLuma 的安装、更新与项目仓库入口；本机未安装 SnowLuma 时，协议端列表不再显示该卡片。
- 概览页 Core 卡片只显示已安装的协议端：未安装 SnowLuma 时不再出现占位卡，NapCat 卡片占满整行。
- 容器部署区不再提供 SnowLuma 镜像拉取与「新建 SnowLuma Bot」入口；已有 SnowLuma 容器仍可在容器管理页管理。
- 新建 Bot 时，本机未安装 SnowLuma 则底座选择不再出现 SnowLuma 选项；编辑已有 SnowLuma Bot 的配置不受影响。
- 新建 Bot 的引导流程移除 SnowLuma 相关步骤。
- SnowLuma 配置缺少组件时，提示不再指向「组件」页安装（该入口已移除），改为提示切换底座或恢复本机 SnowLuma 目录。
- 版本检查不再拉取 SnowLuma 上游 release（仓库已关闭），本地缓存的旧版本号也不再驱动更新提示。

#### 保留能力（已安装 SnowLuma 的机器）

- 启停、配置、登录、WebUI / noVNC、日志与卸载等管理功能全部保留。
- 组件探测与远端 SnowLuma 管理不受影响。
